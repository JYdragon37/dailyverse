# Morning Manna — 서비스 비용 분석

> 작성일: 2026-04-23
> 기준: Firebase(Firestore/Storage/Auth) + WeatherKit + RevenueCat + AdMob

---

## 사용 중인 서비스 스택

| 서비스 | 용도 | 무료 한도 |
|--------|------|----------|
| Firestore | 말씀/유저/묵상 DB | 50K read, 20K write/일 |
| Firebase Storage | 감성 이미지 CDN | 5GB 저장, 1GB 전송/일 |
| Firebase Auth | 로그인 | 10K/월 무료 |
| WeatherKit | 날씨 | 50만 콜/월 무료 |
| RevenueCat | 구독 관리 | 2,500 MAU 무료 |
| AdMob | 광고 수익 | 비용 없음 (수익 발생) |

## 비용 구조가 유리한 이유

### 1. 말씀 데이터는 공유 캐시
- 모든 유저가 같은 말씀을 읽음
- 1명이 읽든 10만명이 읽든 Firestore read는 캐시 후 1회
- `DailyCacheManager` + `AppLoadingCoordinator` 구조가 이를 보장

### 2. 이미지는 CDN 캐싱
- Firebase Storage + CDN → 같은 이미지 반복 과금 없음
- 추후 트래픽 폭증 시 Cloudflare R2 전환 고려

### 3. 알람은 서버리스
- 알람 로직 전부 클라이언트 처리 (AlarmKit / LegacyAlarmEngine)
- 알람 발동 시 서버 호출 없음

---

## 수익 대비 비용 비율

### MAU 10,000 기준
- 전환율 3% → 구독자 300명
- 월 수익: `300 × ₩24,500 × 70% = ₩5,145,000`
- 서버 비용: `~₩165,000 (~$125)`
- **비용 비율: 약 3.2%**

### MAU 100,000 기준
- 전환율 3% → 구독자 3,000명
- 월 수익: `3,000 × ₩24,500 × 70% = ₩51,450,000`
- 서버 비용: `~₩1,860,000 (~$1,410)`
- **비용 비율: 약 3.6%**

## 주의 사항

| 항목 | 리스크 | 대응 방안 |
|------|--------|----------|
| RevenueCat | MAU 2,500 초과 시 과금 시작 | 수익 대비 1~2% 수준으로 관리 가능 |
| Firebase Storage | 이미지 CDN 트래픽 증가 | Cloudflare R2 전환 (100K+ MAU 시) |
| Firestore | 실시간 리스너 남용 시 비용 폭증 | 단발성 fetch 패턴 유지 |
| WeatherKit | 50만 콜/월 초과 시 과금 | OpenWeatherMap 폴백 활용 |

---

## 결론

- **~10K MAU**: 사실상 무료
- **10K~100K MAU**: 월 10~150만원, 수익 대비 3~4% 수준
- **100K+ MAU**: 비용 증가하지만 수익이 더 빠르게 증가
- **구조적으로 서버리스 + 캐시 중심**이라 스케일링에 유리
