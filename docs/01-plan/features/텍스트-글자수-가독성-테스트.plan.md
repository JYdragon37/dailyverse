# Plan: 텍스트 글자수 가독성 테스트

## Executive Summary

| 항목 | 내용 |
|------|------|
| Feature | 텍스트-글자수-가독성-테스트 |
| 시작일 | 2026-04-15 |
| 목표 | 각 화면/필드별 이상적인 글자수 상한선 도출 |
| 결과물 | 콘텐츠 가이드라인에 반영할 글자수 제한 수치 |

### Value Delivered (4-Perspective)

| 관점 | 내용 |
|------|------|
| Problem | 콘텐츠 작성 시 글자수 기준 없어 레이아웃 깨짐 리스크 존재 |
| Solution | 시뮬레이터 실물 테스트로 디바이스별 안전 마진 포함 수치 확정 |
| Function/UX Effect | 모든 iOS 디바이스에서 말씀 텍스트가 레이아웃을 해치지 않음 보장 |
| Core Value | 콘텐츠 팀이 숫자 하나로 품질을 셀프 검수할 수 있는 가이드라인 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | 글자수 초과 시 AlarmStage1(스크롤 없음)에서 말씀이 버튼을 밀어내거나 잘릴 수 있음 |
| WHO | 콘텐츠 작성자 (content-writer 에이전트 포함) |
| RISK | 최소 디바이스(SE 375pt)에서 통과해야 모든 기기 안전 |
| SUCCESS | 각 필드별 숫자 1개씩 — 이 숫자 이하면 어떤 기기에서도 레이아웃 안깨짐 |
| SCOPE | 읽기 전용 테스트 (콘텐츠 가이드라인 수치 도출) — 실제 UI 코드 수정 없음 |

## 1. 테스트 대상 화면 × 필드

### 1-1. 제약 레벨별 분류

| 제약 레벨 | 화면 | 필드 | 폰트 | 스크롤 |
|-----------|------|------|------|--------|
| **Level A (가장 엄격)** | AlarmStage1View | `verseShortKo` | Georgia-Italic 28pt, center, h-pad 32pt | ❌ 없음 |
| **Level B (중간)** | HomeView center overlay | `verseFullKo` | 21pt regular, h-pad 13%↑ 40pt↓ | ❌ 없음 |
| **Level B (중간)** | VerseCardView (HomeView) | `verseShortKo` | 26pt semibold, h-pad 40pt | ❌ 없음 (아래로 밀어냄) |
| **Level C (여유)** | AlarmStage2View | `verseFullKo` | 확인 필요 | 확인 필요 |
| **Level C (여유)** | VerseDetailBottomSheet | `interpretation` | 17pt regular | ✅ ScrollView |
| **Level C (여유)** | VerseDetailBottomSheet | `application` | 19pt regular | ✅ ScrollView |

### 1-2. 테스트 우선순위

**P0 — 이 화면이 깨지면 안 됨:**
- AlarmStage1: `verseShortKo` (스크롤 없음, 버튼 영역과 경쟁)
- HomeView: `verseFullKo` (스크롤 없음, 날씨 위젯과 경쟁)

**P1 — 이상적인 UX 범위 확인:**
- VerseCardView: `verseShortKo`
- AlarmStage2View: `verseFullKo`

**P2 — ScrollView라 덜 엄격하나 가이드라인 필요:**
- BottomSheet: `interpretation`, `application`

## 3. 구현 계획

### Step 2: AlarmStage2View verseFullKo 폰트 스펙 확인 (Read)
