슬로건: "매일 아침, 알람이 아닌 말씀으로 눈을 뜨세요"

타깃: A타입 크리스천 — QT 하고 싶지만 작심삼일인 사람. 바쁘고 바빠서 못 하는 사람.

핵심 가치: "노력 없이도 말씀 앞에 서게 해준다" — 알람을 끄는 행동만으로 자동으로 말씀을 만남

핵심 차별화: 알람 + 성경 말씀. 기존 알람 앱을 대체하는 포지셔닝. "또 하나의 앱"이 아닌 "이미 쓰는 알람에 말씀만 얹는 것"

**Why:** 포지셔닝이 확정되어 모든 온보딩 카피와 UX 결정의 기준이 됨

**How to apply:** 온보딩 화면 텍스트, 알람 설정 화면 프레이밍, 마케팅 카피 작성 시 이 포지셔닝에서 벗어나지 않는지 확인
